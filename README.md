# Demos

Interactive demo projects by Aria Tajeri. Each demo lives in its own folder and is served with GitHub Pages from the `main` branch root.

| Folder | Demo |
|---|---|
| `trading-bot-panel/` | Multi-platform trading bot control panel (Spanish UI): strategy config (EMA crossover / RSI), simulated MT5, Binance and BingX connectors, backtest on generated price data, risk settings, paper trading, alert previews and an exportable log. |

All brands, accounts, prices and connections in these demos are fictional. Nothing connects to a real broker or exchange, and no orders or messages are sent. Results shown are on invented data and do not indicate future returns.
